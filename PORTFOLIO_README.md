# MSc Artificial Intelligence — e-Portfolio

This website is an edited version of the **Forty** HTML5 UP theme supplied in `html5up-forty.zip`. The existing HTML/CSS/JavaScript/assets are retained and adapted for an academic portfolio. **No web framework, installation, build step, or server is required.**

## Open it

Double-click `index.html` in a web browser, or upload the folder contents to a static host (e.g. your university web space, GitHub Pages or Netlify). Keep `assets/` and `images/` alongside the HTML pages.

Every module includes a link to the corresponding course page at my-course.co.uk; access may require a university login.

## Browser-ready notebooks
All Jupyter notebooks now have standalone HTML renderings for direct viewing in web browsers. Each portfolio link offers **View notebook** (HTML) and **Download original** (.ipynb). HTML copies display only outputs saved in the original notebooks; they do not execute code.

## Notebook downloads (Firefox and local browsing)
The Download notebook links lead to individual ZIP archives containing the original `.ipynb`. Browsers may display raw JSON instead of downloading `.ipynb` on local `file://` pages, even with the HTML `download` attribute. ZIP archives download reliably. Extract the ZIP to obtain the unchanged notebook. HTML previews and original `.ipynb` files are retained.
